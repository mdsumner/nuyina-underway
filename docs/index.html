Nuyina underway

Raw underway data from RSV Nuyina for data science: position, met and sea-surface measurements every minute, cached as Parquet and topped up from the live AAD GeoServer feed. A map to prove it's live, and code to use it.

This is science-dev work by Michael Sumner, not an official Australian Antarctic Division publication. For the official view of the ship, see below.

Use the data

The cache is one Parquet file on a GitHub release, refreshed by GitHub Actions; the live feed is the WFS layer underway:nuyina_underway. The R package joins the two, so you get everything up to the last few minutes.

R, with nuyina.underway

install.packages("remotes")
remotes::install_github("mdsumner/nuyina.underway")

d <- nuyina.underway::nuyina_underway()   # cache + live, in time order
tail(d)

R, just the cache

url <- "https://github.com/mdsumner/nuyina-underway/releases/download/v0.0.1/nuyina_underway.parquet"
d <- arrow::read_parquet(url)

Python

import duckdb

url = "https://github.com/mdsumner/nuyina-underway/releases/download/v0.0.1/nuyina_underway.parquet"
df = duckdb.sql(f"SELECT * FROM '{url}' ORDER BY datetime DESC LIMIT 1000").df()

# or the whole file with pandas
import pandas as pd
df = pd.read_parquet(url)

DuckDB

## curl https://install.duckdb.org | sh
SELECT date_trunc('day', datetime) AS day, count(*) AS n
FROM 'https://github.com/mdsumner/nuyina-underway/releases/download/v0.0.1/nuyina_underway.parquet'
GROUP BY 1 ORDER BY 1 DESC LIMIT 10;

GDAL, the live feed

# latest 10 records as GeoJSON, straight from the WFS
ogr2ogr -f GeoJSON /vsistdout/ \
  "WFS:https://data.aad.gov.au/geoserver/ows" \
  -sql "SELECT * FROM \"underway:nuyina_underway\" ORDER BY datetime DESC" -limit 10
