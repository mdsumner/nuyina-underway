Nuyina underway

Sites built on the RSV Nuyina underway feed. The data: nuyina_underway.parquet (updated by GitHub Actions from the AAD GeoServer WFS).

  • Proximal: live vessel track with crow-fly lines and distance metrics.
  • Sea ice map: the vessel over daily sea ice, rendered by seaice.map to Pawsey object storage.
  • nuyina.underway: R package to read the underway data up to minutes-recent, from the efficient Parquet cache here plus the live WFS for anything newer.
